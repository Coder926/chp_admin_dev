# Services Help

## Overview

Services define the types of work available in the platform. Each service is associated with an appliance type.

## Managing Services

- **Create** — Click the Create button to add a new service
- **Edit** — Click a service to open the detail slide-over
- **Delete** — Remove services that are no longer offered

## Service Properties

- **Name** — The display name shown to customers and admins
- **Type** — Categorizes the service (e.g., repair, installation, maintenance)
- **Appliance Type** — Links the service to a specific appliance category

## Tips

- Services must have an associated appliance type
- Deleting a service may affect existing bookings — review carefully
