# Schedules Help

## Overview

Schedules define recurring availability patterns for engineers and service windows.

## Managing Schedules

- **Create** — Define a new schedule with day-of-week, time range, and capacity
- **Edit** — Modify an existing schedule's settings
- **Link** — Associate schedules with calendars to control availability

## Schedule Properties

- **Days** — Select which days of the week the schedule applies
- **Time range** — Set start and end times for service availability
- **Capacity** — Maximum number of bookings per time slot

## Tips

- Schedules are linked to calendars for regional availability
- Changes to a schedule affect all linked calendars immediately
