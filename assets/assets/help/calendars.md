# Calendars Help

## Overview

Calendars group schedules by region and control which dates are available for bookings.

## Creating a Calendar

1. Click **Create** in the top-right of the list panel
2. Enter a name for the calendar
3. Select one or more regions to associate
4. Submit the form

## Managing Calendars

- Click a calendar in the list to view its details in the right panel
- Each calendar shows its associated regions and linked schedules
- Changes to a calendar's regions affect availability across all linked schedules

## Tips

- A calendar must have at least one region
- Region changes take effect immediately for all downstream schedules
