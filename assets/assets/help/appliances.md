# Appliances Help

## Overview

Appliances define the categories of equipment that services can be performed on (e.g., heaters, ovens, dishwashers).

## Managing Appliances

- Create appliance types to categorize your services
- Each appliance type can have multiple associated services
- Delete appliance types that are no longer needed

## Tips

- Appliance types are referenced by services — check for dependencies before deleting
