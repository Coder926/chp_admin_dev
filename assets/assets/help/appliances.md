# Appliances and Brands

Select an appliance type to view its catalogue models. Each model has a stable appliance ID, a Brand, and model name/code.

Use **Brands** to view manufacturers. Super admins can add Brands, correct their display names, or deactivate them. Other admin roles can read the catalogue and price history.

When creating an appliance, select its type and Brand, enter its model identity, and set the initial GBP hardware price and extra installation fee. Edit an appliance to adjust its display name or active status. Its type, Brand, and model code remain fixed.

Select an appliance and use **Change price** to create a new price version. Price rises and drops preserve the model ID and service mappings. **Price history** shows current and superseded versions. Existing bookings retain their agreed price; changing the catalogue does not reprice them.

If another administrator changed the price first, reload the current version, review it, then submit your change again. Deactivate an appliance only when the model is no longer offered.
